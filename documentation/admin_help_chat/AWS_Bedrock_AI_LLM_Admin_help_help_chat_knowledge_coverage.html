Admin Help knowledge coverage

Admin Help answers from a stamped knowledge pack in this repository. New pages, including /admin/school, stay invisible to the chat until those files name them. The chat does not call adwiise-agent-service.

Why this stays keyword retrieval, with no vector database and no RAG index: Vector database and RAG analysis.

Call path

The floating Help button posts to /api/admin/help-chat. That route matches the question against curated chunks, then calls Bedrock InvokeModel in us-east-1.

Default model: us.anthropic.claude-sonnet-5-5. The same model id is used for image-text scanning in the Java service and for retail Ask, but those are different prompts and different callers.

Do not route Help through the backend image scanner or through the AI engine /v1/chat. Retail Ask is Admin, then Spring, then the AI engine, then Bedrock. Help stays in this Next.js app.
What is stored

There is no vector database. Long-term context is TypeScript:

  • src/lib/adminHelp/knowledge/hubGuides.ts — one summary per Admin Home tile
  • src/lib/adminHelp/knowledge/routeMap.ts — path, tasks, and suggested questions
  • src/lib/adminHelp/knowledge/howTos.ts — step-by-step answers, including school contacts

The model is instructed to use only the chunks that the keyword lookup selected.

Check for missing tiles

After adding an Admin Home tile, run check-admin-help-coverage.mjs. It prints every tile label, path, and summary, and exits with an error when a key has no hub guide or route.
