Prefixes to use when you approve

Approve in this order

Open a request from the pending list and approve it with the prefix named in its description. Leave the sequence on the auto-generated next number. The first approval of a prefix takes that next number. The second approval of the same prefix takes the following number.

The number 13 is the next unused sequence the form calculated on November 11, 2026. Sequences already used by other tenants are skipped. If another tenant with the same prefix is created before you approve these, the next number will be higher than 13. Read the generated tenant ID on the approve screen before you confirm.

Why each request has its own email

One pending request per contact email

The server rejects a second PENDING request that uses an email already waiting for review (error.emailpending: “A request from this email is already waiting for review.”). The Add Request form has no separate email field. It copies the selected organization’s contact email at the moment the organization is selected.

To save three requests per school, the organization contact email was changed in the organization form, the organization was selected again so the new request copied that email, and the request was saved. After the third request for each school, the organization contact was put back:

  • BST School Demo One is maya.chen@bst-school-demo-one.test, contact person Maya Chen.
  • BST School Demo Two is luis.ortega@bst-school-demo-two.test, contact person Luis Ortega, phone 555-010-2002.

The emails stored on the requests themselves stay as they were at save time. They are listed in the tables above. Approving or denying a request frees that email for another pending request.
