Platform billing support playbook

Search /admin/platform-billing by organization name, website tenant id, contact email, Stripe customer id (cus_), subscription id (sub_), or invoice id (in_). Export ledger includes Stripe ids. Organization search Excel does not.

QuestionScreenLedger statusWhat to say
I was charged twice Billing area, Export ledger, filtered by the organization Two PAID rows with different invoice ids are two real invoices. Two rows with the same Stripe event id should not exist. Read the invoice ids. A ticket purchase in the same Stripe account is not a platform charge. Compare the period start and period end.
I cannot pay /admin/billing for that website No OPEN or PAID row yet If the page says the organization pays, this website has no Pay button. If the switch is off, a super-admin must turn it on. Then the payer opens Pay.
This site is free Website billing page, status line No charge, or only VOID after a cancel Status COMPLIMENTARY means the charge switch is off. A covered note means the organization subscription pays for it. Neither one should be locked.
Cancel Billing page for the payer. Covered websites have no cancel button. VOID on the subscription-deleted event Cancel at period end keeps access until the period ends. Cancel now is a super-admin action and returns the row to complimentary immediately.
Payment failed Billing page and the Customer Portal button FAILED The payer updates the card in the portal and opens Pay again. After grace with no paid period, status is LOCKED and admin tools redirect to billing. The public site stays up.
We moved a website Organization page, billing scope, and the website billing page Unchanged until the new payer is invoiced An organization billed once covers the moved website and cancels that website’s own subscription at period end. Per-website mode removes the covered note and does not start a charge.
